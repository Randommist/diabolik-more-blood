# Правила качества перевода

## Принципы

- Сохранять весь смысл оригинала, стиль, дерзость и оттенки; не сглаживать тон и не добавлять грубость. Русский должен читаться естественно.
- Не добавлять пояснений вместо оригинала. Не создавать цензурирующих заглушек.
- Непереводимое или требующее отдельного решения оставлять в оригинале (не добавлять запись в файл сцены).
- Именные суффиксы (-кун, -сан, -тян, -сама) передавать при имени, только если они есть в японской строке; должности и обращения остаются словами (см. `AGENTS.md`).

## Порядок работы

1. Прочитать страницу целиком и соседний контекст.
2. Написать полноценную русскую реплику; проверить детали, причинность, отрицания, род, голос говорящего.
3. Распределить по игровым строкам внутри страницы. Не переносить смысл между разными страницами.

## Геометрия

Окно текста — 480×272; перенос строк делает `tools/reflow.py` при сборке. Не сокращать мысль только ради длины японской строки. Пустые записи сохранять; учитывать накопление текста между подтверждениями.

## Варианты выбора

Сначала полный перевод, потом проверка кодировки и 39 доступных байт. Лексику сверять со сценой: объекты, вежливость, неоднозначные слова и значение «いい» зависят от контекста. Согласие нельзя превращать в отказ; одинаковые японские варианты в разных сценах могут требовать разных русских.
