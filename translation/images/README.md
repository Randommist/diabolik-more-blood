# Переведённые картинки

- `jobs.json` — список заданий: id картинки, каталог и имя в INSTALL.CPK, размер, описание.
- `ru/<id>.png` — готовые русские версии (60 шт.). Их `tools/build_images.py` конвертирует в TIM2 и подставляет в INSTALL.CPK при сборке.

Оригиналы в репозитории не хранятся: их извлекает `tools/extract_images.py` из вашего ISO (`build/assets`, `build/png`). Чтобы заменить картинку, положите новый PNG того же размера в `ru/` и пересоберите (`bash scripts/build-all.sh`).
Подробности о том, какие картинки содержат японский текст, — в [../../docs/image-assets.md](../../docs/image-assets.md).
